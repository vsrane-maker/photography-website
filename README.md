**Photography Website**

As a professional photographer, I decided it would be a great project to create my own website for my brand. 
Having a website allows me to display my portfolio in an elegant manner and allow my clients to create their own bookings. 

I decided to implement this feature using AWS Simple Email Service as well as Resend. AWS Simple Email Service
transfers the client's information to me in a secure fashion while Resend sends the client a confirmation email. 

Finally, I bought a domain and deployed the project through vercel.

This was a great project to introduce myself to web development and AWS products. I hope to add more to my
website by implementing react and other tools to optimize its performance in the future.
